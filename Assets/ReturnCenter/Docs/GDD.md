# RETURN CENTER — GDD baseline

## Product identity
A Steam Premium first-person systemic management simulation about reverse logistics: inspect returned products, choose disposition routes, then turn those decisions into an automated processing system.

## Core loop
Receive → Inspect → Diagnose → Decide → Process → Recover Value → Find Bottleneck → Upgrade/Automate → Accept Harder Contract → Repeat.

## Vertical Slice proof
The slice must prove: **Manual → Pain → Automation → New Bottleneck → Policy → Improvement**.

## Kill criteria
- Automation makes the player idle.
- The returns theme has no gameplay consequence.
- One disposition policy dominates every situation.
- Bottlenecks are unreadable.
- Product asset volume grows faster than systemic depth.

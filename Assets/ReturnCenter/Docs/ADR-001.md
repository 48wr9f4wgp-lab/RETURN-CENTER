# ADR-001 — Engine & architecture

Status: Accepted

- Engine: Unity 6.3 LTS target
- Language: C#
- Target: Windows / Steam
- Domain logic remains independent from Unity APIs where practical.
- Runtime GameObjects are presentation, not canonical simulation state.
- Conveyor/automation systems will use deterministic logical state rather than relying on rigidbody force chains.
- Save schema will be versioned before persistent slice layouts are introduced.

Current bootstrap intentionally uses a debug IMGUI HUD and legacy Unity input APIs to minimize dependencies before the first verified editor build. These are **temporary bootstrap surfaces**, not the final UI/input architecture; UI Toolkit and Input System migration is queued after the first successful Unity build.
